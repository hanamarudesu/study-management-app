# 学習管理アプリ 画面設計

## 1. 画面一覧

| No. | 画面名 | 役割 |
|---|---|---|
| 1 | ログイン・ユーザー登録 | ユーザー認証 |
| 2 | ダッシュボード | 今日の学習内容や学習状況を確認 |
| 3 | 学習開始・タイマー | 学習時間を計測 |
| 4 | 学習記録 | 学習内容や進捗を記録 |
| 5 | 学習履歴 | 過去の学習記録を確認 |
| 6 | 学習分析 | 学習時間や分野ごとの状況を分析 |
| 7 | 学習対象管理 | 資格・学校などの学習対象を管理 |
| 8 | 目標設定 | 学習目標や試験日を設定 |

---
