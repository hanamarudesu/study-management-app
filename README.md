# StudyHub

## 概要
資格・学校科目の学習時間や進捗を
一元管理するWebアプリケーション。

## 開発背景
複数の資格学習と学校の学習を並行する中で、
学習時間や進捗を管理しづらいという課題を感じ、
開発を開始しました。

## 主な機能
- 学習時間の記録
- 学習タイマー
- 学習目標の設定
- 学習進捗の可視化
- 学習データの分析
